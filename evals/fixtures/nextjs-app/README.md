# todo-app

A Next.js app (App Router, TypeScript) with:

- a header with a dark mode toggle
- an editor that lists code blocks
- pricing cards for a Free and a Pro plan
- a settings page with an editor theme select and an API key button
- coupon discounts at checkout
- a CSV import action that doesn't parse files yet
- `POST /api/render`, which requires an API key and returns placeholder bytes instead of a rendered image
